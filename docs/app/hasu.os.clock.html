About this app

Clock — alarms with repeat days and snooze, stopwatch with laps, a timer that rings from the background, and world clocks.

🆕 What's new in v1.14

FIXED: the alarm editor now scrolls — on a short or sideways screen its Save button used to sit below the screen and could not be reached at all. FIXED: a long message in a confirm dialog (for example the crash details) now scrolls too, so its buttons stay reachable. NEW: the World tab says so when no cities are left, instead of showing a blank list. FIXED: the live clock no longer rebuilds its date formatters on every one-second tick. DESIGN: the app icon on the About page now sits on a glass tile. The Guide and About pages list the editor fix.
